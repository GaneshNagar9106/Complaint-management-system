About Samadhan

A simple complaint management system built as a web hosting mini project.

Why this system

Paper complaints get lost and nobody knows who is handling them. Samadhan gives every complaint a reference ID, a category and a visible status, so the person who complains and the person who resolves it see the same record.

What it does

  • Citizens file a complaint through a validated online form.
  • Every complaint gets a unique ID and the date it was received.
  • Status can be checked using only the ID.
  • Staff log in to update status and add a remark.

Built with

HTML5, CSS3, Bootstrap 5 and JavaScript. Complaints are stored in the browser's localStorage. Hosted over FTP.
